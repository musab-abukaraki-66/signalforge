# Product brief

## Vision

Show the complete data lifecycle on a real e-commerce problem: raw data in, evidence-based decisions out, with every step reproducible and every claim traceable.

## Scope (initial)

**In scope:** a marketplace analytics case study built on one public e-commerce dataset; ingestion and validation; a layered analytical model; validated KPIs; one executive Power BI dashboard; baseline predictive models with honest evaluation; decision support with explicit assumptions.

**Out of scope for now:** real-time streaming, a custom web frontend, LLM-generated analysis, distributed infrastructure, paid services, and any private or personal data.

## Target users

| User | Needs |
|---|---|
| Marketplace analyst | Trustworthy KPI definitions and a model they can query |
| Operations / logistics manager | Delivery performance, root causes, and what to change |
| Category / seller manager | Seller and product performance with fair comparisons |
| Executive | A short dashboard that ties numbers to decisions |
| Data team / reviewer | A reproducible reference: how it was built and how to rerun it |

## Success criteria

- Anyone can clone the repository, follow the docs, and reproduce every number.
- Each KPI has one documented definition, source fields and grain.
- Every model reports evaluation against a stated baseline, with leakage controls.
- Every recommendation labels what is observed, forecast, assumed, or causal.

## Non-goals and honesty rules

No fabricated metrics, screenshots, customers or model results. Planned features are labelled planned until their roadmap exit criteria are met.
